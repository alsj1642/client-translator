# 눈치봇 영상 키트

모든 눈치봇 영상이 따르는 모양·규칙·재료예요. 영상별 기획서(`videos/<영상>-prompt.md`)는 여기를 따르고 이야기만 더해요.
근거: `DESIGN.md`(디자인 가이드, 최우선), `styles.css`, `.streamlit/config.toml`, `CLAUDE.md`, `app.py`, `hero/`, `buddy/`, `vent/`.
**이 파일과 저장소의 규칙이 다르면 저장소(DESIGN.md)가 이겨요.**

## 인터뷰에서 정한 것 (2026-11-02)
- 쓰는 곳: 포트폴리오/발표용 소개 영상, 소리 있음. 화면 16:9. 길이 45~60초.
- 음악: 무료 음악 추천받기 → 후보를 드리고 사용자가 고름 (라이선스 링크 필수). **아직 미정.**
- 꼭 보여줄 것: 번역(피드백 → 카드 4장), 하소연 탭, 로봇 '눈치봇'의 표정, 방어 동작(짧은 입력·개인정보 안내).
- 재료: 브랜드 = 눈치봇 로봇이 주인공 + 앱 화면 · 글자 = 장면 사이 큰 한 줄 · 연결 = 박자에 맞춘 깔끔한 컷 · 더할 것 = 마우스·타이핑, 흐르는 띠와 형광 연두 포인트.
- 끝 장면: (기획서 확인 때 정함)

## 꼭 지킬 규칙
- 문구는 모두 '~요' 체, 디자이너 편을 드는 친한 친구 말투. (DESIGN.md §1)
- 글꼴: Mona12 픽셀 글꼴, 굵기 400. 굵게(700)는 '눈치봇👀' 이름에만. Pretendard는 Mona12에 없는 글자 대비용. (DESIGN.md §3)
- 선: 1.5px 검은 선. 그림자는 흐린 그림자 대신 `4px 4px 0 #111` 선 그림자만. (DESIGN.md §1, §4)
- 면: 흰색·미색만. 포인트 색은 형광 연두 하나. 예외는 불(하소연 불태우기)과 반짝이(로봇 등장)뿐. (DESIGN.md §1, §2)
- 움직임: 차분하게, 한 번에 한 곳만. 빠른 깜빡임·여러 곳 동시 움직임 금지. (DESIGN.md §1 원칙 4)
- 요청한 것만 넣기. 장식을 위한 장식 금지. (DESIGN.md §1 원칙 5)
- 쓰지 않는 것: 파스텔·파란 박스, 격자 배경, WebGL 배경, 커서 물결, 로봇 뒤 후광, 암호 풀리듯 바뀌는 글자, 돌아다니는 로봇, 프린터 출력 효과, 버튼 화살표 아이콘. (DESIGN.md §12)
- 제품 정책: 실명·연락처·회사명은 넣지 않기 (`app.py` 안내 문구, CLAUDE.md). 영상 속 개인정보 예시는 `김00`, `010-0000-0000`처럼 가짜 값만.

## 화면 (1920×1080, 60fps, 밝은 화면)
- 틀: 앱처럼 흰 바탕 전체 화면. (DESIGN.md §7 메인: 흰 배경, 박스 없음)
- 큰 한 줄: Mona12, 검정, 장면 사이에 단어씩. 강조 한 덩어리에만 형광펜(메인 카피와 같은 방식).
- 장면 안 글자는 앱 화면의 글자만. 화면 가장자리 100px 안쪽에 둠.

## 색
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 | `#FFFFFF` | 화면 바탕, 종이·말풍선 면 |
| 잉크 | `#111111` | 글자, 모든 선, 선 그림자 |
| 미색 종이 | `#F4F4EF` | 박스 바탕, 접힌 모서리 |
| 옅은 회색 | `#EBEBE6` | 회신 초안 복사 상자 |
| 형광 연두 | `#76F25C` | 주요 버튼, 고른 탭, 흐르는 띠, 형광펜 |
| 보조 글자 | `#55554F` | 작은 안내 문구 |
| 흐린 글자 | `#8A8A85` | 입력 칸 안내 |
| 불 | `#FF7A1A` `#FFC93C` `#FFF3C4` | 쓰레기통 불태우기에만 |

## 글자 크기 (1080p 기준)
- 큰 한 줄: 120~140px. UI 글자는 앱 크기의 약 1.5배(입력 27px, 버튼 24px)로 키워 화면에서 읽히게.

## 로고와 로봇
- 주인공: 3D 로봇 '눈치봇' (`hero/robot-character.js`). 표정 6개: 기본, 정중(^ ^), 생각 중, 팩폭, 오류(빨간 X), 하트.
- 로봇은 스스로 시계를 돌려요(브라우저 애니메이션 루프). 영상에서는 **영상 시간으로 움직이는 쌍둥이**를 만들어야 해요. 시작 전 표정 6개 포즈 시트를 먼저 찍어요.
- 로고 SVG(`assets/logo-mark.svg`)는 현재 화면 디자인(흑백+연두)과 색이 달라서 영상에서는 쓰지 않아요. 이름은 '눈치봇👀' 글자로.
- 금지: 돌아다니는 로봇, 로봇 뒤 후광.

## 움직임
- 앱 값: 버튼 들림 0.15초, 로봇 점프 0.75초, 구겨서 던지기 약 2초, 불태우기 약 4초, 형광펜 0.5초. (DESIGN.md §8)

## 할 수 있다고 말해도 되는 것
- 하는 일: 모호한 피드백을 해석, 충돌하는 요구, 되물을 질문 후보, 회신 초안 4장으로 정리. 너무 짧거나 개인정보가 보이면 번역하지 않고 안내. 하소연을 구겨 던지거나 불태우고 로봇의 한마디를 받음.
- 하지 않는 일: 정답을 보장하지 않음(AI 답은 매번 조금씩 달라요). 클라이언트에게 대신 보내지 않음. 속마음을 단정하지 않음(프롬프트 규칙).
- 영상 속 번역 결과는 **실제 측정 결과**(`results/v2_1_run.csv`)에서 가져와요. 지어낸 답을 쓰지 않아요.
- 피할 말: '완벽하게', '정확히', '100%'.
